# Transformer 论文导读

## 研究背景

循环神经网络按顺序处理 token，难以充分并行，也不容易捕捉距离较远的依赖。Transformer 使用自注意力机制建立序列中不同位置之间的直接联系，使训练过程更适合并行计算。

## 自注意力机制

自注意力把输入映射为 Query、Key 和 Value。Query 与 Key 的相似度经过缩放和 softmax 后形成权重，再对 Value 加权求和。缩放点积注意力需要除以 key 维度的平方根，避免点积过大导致梯度过小。

## 多头注意力

多头注意力在不同投影子空间中并行计算注意力，再拼接各个头的输出。不同头可以学习句法、语义或位置关系等不同模式。多头并不是简单地重复同一个注意力计算。

## 位置编码

自注意力本身不包含顺序信息，因此需要位置编码。原始论文使用不同频率的正弦和余弦函数，让模型区分 token 的位置。阅读后续模型时，可以对比旋转位置编码等改进方案。

## 复习问题

为什么缩放点积注意力需要缩放？多头注意力解决了什么问题？去掉位置编码后模型会失去什么信息？这些问题适合用来检查自己是否真正理解论文，而不只是记住结构图。
